# humanlist

日常・仕事のタスク、習慣（早寝早起きなど）、忘備録、雨の通知をまとめて管理する Web アプリ。
ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます（データはブラウザの localStorage に保存）。

- **今日**: 1日のタイムライン。時間の決まった予定と「時間未定」を一覧
- **WBS**: 2週間分の表。継続作業の予定時間バー、完了予定日、日ごとの合計作業時間
- **タスク**: 追加・編集。継続作業の進捗と完了予定、習慣の連続日数、単発タスク
- **メモ**: 忘備録

## 種類
| 種類 | 用途 |
|---|---|
| 単発タスク | 日付・時刻・所要時間はすべて任意 |
| 継続作業 | 合計時間と1日の作業量から完了予定日を自動計算。サボると翌日以降が自動でずれる |
| 習慣 | 曜日ごとのチェック。連続達成日数 |
| メモ | 日時なし |

天気は Open-Meteo（キー不要）。「タスク」画面の「天気の地点を設定」で現在地と通知を許可できます。

## テスト
`node` で `core.js`（完了予測ロジック）を検証できます。

## 更新の仕組み
デプロイ時にコミットIDを `index.html`（ファイルURLの `?v=`）と `sw.js`（キャッシュ名）へ埋め込みます（`.github/workflows/pages.yml`）。
通信できるときは常に最新を取得し、開いたまま戻ったときも更新を確認して自動で再読み込みします。オフライン時だけ保存分を使います。
